# Hospital Management REST API

A beginner-friendly Hospital Management application built using Java, Spring Boot, Gradle, REST APIs, Docker, and basic frontend technologies.

This project demonstrates:
- Backend API development using Spring Boot
- RESTful API design
- Frontend to backend communication using HTTP requests
- CRUD operations
- Unit testing
- Docker containerization
- Git and GitHub workflow

---

# Features

- Add new patients
- View all patients
- Search patient by name
- Delete patient by name
- REST API endpoints
- Simple frontend using HTML and JavaScript
- Unit testing with Spring Boot Test and MockMvc
- Dockerized backend application
